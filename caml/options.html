Title Rules

By default the link text is the page title. Rules transform it per website: the first rule whose URL regexp matches the URL and whose title regexp matches the input pattern is applied.

How rules work
URL regexp
The rule only applies to URLs matching this regular expression.
Input pattern
Text the title regexp is matched against. Default is {{title}}, use the variables below to add the URL or the selected text.
Title regexp
Regular expression matched against the input pattern.
Replacement
New link text, can reference the regexp groups ($1, $2…).
Prefix
Optional text added before the link, e.g. a Slack emoji like :github:.

Input pattern, replacement and prefix accept the variables {{title}}, {{url}} and {{selection}}.
